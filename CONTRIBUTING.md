# Contributing To Any "ST - Another Journey" Add-On
Hello! I'm glad you want to contriubte to one of these add-ons!

The only one being worked on at the moment is Heated Desert, so please focus on that.

## Bug Reports
- Make sure it hasn't already been reported
- Don't use AI to write bug reports

## Pull Requests
- Make sure there isn't already a pull request for the thing you're trying to add.
- Don't use AI for the pull request, also don't use AI to make anything in the pull request.
